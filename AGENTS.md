# Git

Conventional commit subject, 50 characters max. Body: up to 3 bullets, 50 characters each, not capitalized. Run `git config core.hooksPath .githooks` once per clone; the commit-msg hook enforces this.

# Discussion

Before working, read open issues with `gh issue list` and the files in `docs/decisions/`. Discuss in the issue; commit the outcome to `docs/spec.md` when it changes behavior, otherwise to `docs/decisions/`, and close the issue with the commit.
