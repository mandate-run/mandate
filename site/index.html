An agent handed a wallet will spend it. Mandate is the layer that decides whether a purchase is worth making at all.

Given a purpose, a budget and hard constraints, it collects live quotes over x402, competes plans against each other, pays one signed Hedera transfer per purchase, and writes a receipt for every decision to Hedera Consensus Service.

The decision

Three ways to answer the question. It takes the cheapest one that can still finish.

Every figure below comes from a real run on Hedera testnet, rendered from the JSON report that run emitted. Expected is what the plan should cost. Bound is its worst case. A plan is only eligible if its bound fits the budget, so the runtime can never start something it cannot finish.

The payments

Three signed transfers, each proven from the mirror node.

Settlement is never taken from an HTTP response. The runtime reads the consensus records for its own transaction id. Every id below links to HashScan, and each one can be checked directly against the Hedera mirror node.

What it found

Five pools screened. One had moved.

The runtime screened all five, then bought transaction-level evidence only for the pool that mattered. Every claim is computed from purchased facts; a model only writes the prose, and each number in it is checked back against the evidence.

The refusal

When no plan can guarantee coverage, it spends nothing and says what completion would have cost.

A second real run, with the budget lowered to 0.0030 HBAR. All three plans are rejected before a single payment is signed. This is the product, not a failure.

Verified independently

An application is never its own oracle.

Payment behaviour is checked by Proctor, a harness in the same repository. Its task contracts have two halves: one reads the buyer's own report, the other reads what Proctor measured itself from the seller's journal and the buyer's ledger. A check passes only when both agree. Proctor caught a real double-payment bug during development from the journal, not from anything the buyer said about itself.
